# Censo Nominal CENSIA 2026 — Jurisdicción Sanitaria XIX Texcoco

Pantalla web de captura y seguimiento del censo nominal de vacunación (formato CENSIA 2026).
Los datos **no** se guardan aquí: la página llama al servidor de Google Apps Script del proyecto.

Este repositorio contiene solo la página publicada (generada con `motor/web.js` del proyecto
CENSIA-VACUNACION). No editar a mano: regenerar y volver a publicar.
